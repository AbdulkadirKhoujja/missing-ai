What this does — and doesn't — do

This opt-in instant flow requires no bulk export and sends no input to Missing AI: the page's Content Security Policy blocks JavaScript network connections. Data stays in browser memory until you close or clear the session. The optional downloaded JSONL file is unencrypted. The quickstart does not automatically access other ChatGPT conversations and does not save to your connected private MCP server. Current results are keyword-based suggestions, not verified semantic truth. For later, larger imports use the full history preview and the private MCP documentation.
