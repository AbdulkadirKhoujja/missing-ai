FREQUENT QUESTIONS

What Missing AI can — and can't — tell you.

Is it free?

Yes. The public browser checker is free and open source under the MIT licence, with no account needed. The remote MCP connector is a separate controlled beta.

Does it prove the AI is wrong?

No. The web checker looks for wording overlap and suggests lines to review. The AI-chat workflow checks exact answer quotes and reference accounting; the host model's interpretation can still be wrong.

Can I import assignment or client URLs?

Only public HTTPS HTML or text pages can be imported. Login-required pages and PDFs are not supported by the public URL importer. Do not send confidential briefs to this beta service.

What happens to my text?

The browser's paste-and-check feature runs locally. Loading a public URL sends that URL to the server; ChatGPT/Claude MCP requests send source text and the AI answer to a remote service. Operational logs and provider processing may apply. Read the data-handling explanation.

Can developers contribute?

Yes. See the contribution guide, report reproducible bugs or propose improvements to accessible UI, source extraction and tests.

Important: The website performs a wording-based check, not semantic or implementation verification. Paraphrases may be flagged and omissions may be missed. MCP validation checks evidence structure, not whether the AI host's reasoning is correct. Never enter secrets, confidential client information or sensitive personal data.
