EARLY PREVIEW · OPTIONAL · LOCAL-FIRST

Check what your AI
might have forgotten.

Import your own ChatGPT conversations.json export, then compare a new AI answer with relevant earlier messages. Nothing you import is submitted to the Missing AI server by this page.

Important: Earlier chat claims are not independent proof of access, completion, or current state. Results are suggestions to verify, not semantic fact-checking. Do not import third-party or client data without permission. Review your export first.

01

Load your history

From your own ChatGPT data export, select the conversations.json file (not the ZIP). Supports files up to 25 MB. Only user and assistant text from each conversation's active branch is imported.

No history loaded. We never automatically access your ChatGPT account.

02

Add earlier evidence manually

For conversations you don't have in your export, enter a historical note or a short quoted excerpt. A manual note is marked as user-provided, not verified.

03

Optional encrypted device storage

Nothing is retained by this page after you close it unless you choose to save an encrypted copy in this browser. The saved copy uses AES-GCM and a passphrase-derived key. The passphrase is not stored or recoverable.

Stored only if you explicitly choose Save. Local browser storage can be cleared by your browser or device.

04

Review an AI answer

Paste the AI's latest answer. Missing AI searches related history and highlights possible repeated access requests or previously completed work.

Review results and sourced quotations will appear here.

Privacy and integration limits

This preview runs its comparison in the browser. The file input does not upload your JSON to the remote MCP API. If you opt to save, an encrypted copy is stored using browser IndexedDB under this site's origin. The page's network policy blocks JavaScript connections. Browser extensions, compromised devices, and browser-profile access are outside this feature's protection. There is no automatic ChatGPT or Claude conversation-history API sync; users import or supply the information they authorise. This is a local-only early preview, not an audited secure document vault.
