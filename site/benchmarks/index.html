OPEN RESEARCH · SYNTHETIC FIXTURES

Published results, with clear limits.

Missing AI shares reproducible checks of its wording-based checker, including false alarms and missed omissions. The current fixtures are author-labelled synthetic examples—not independently verified real-world accuracy.

Reproducible benchmark data

View the latest release-build synthetic benchmark JSON with the exact source commit, generation date, test cases, denominators and results. The JSON is generated by code as part of each reviewed site deployment; it is not manually invented marketing data.

See dated public GitHub Actions benchmark runs for the daily read-only tests and downloadable artifacts (subject to GitHub access and retention). Daily reruns of unchanged source are not progress.

What we measure

For each deliberately synthetic source requirement and AI answer, the checker reports whether the wording suggests follow-up. The summary reports omissions detected, missed omissions and covered-case false alarms using published, author-supplied labels. Uncertain answers remain an explicit category.

Which engine is actually live?

lexical-v1 is the current free browser checker. lexical-v2 is an undeployed experimental comparison. A good score on an authored fixture cannot establish either engine's general reliability.

What about ChatGPT and Claude?

The optional MCP beta has host-assisted semantic grouping and mechanical quote/reference checking. The independent semantic evaluation has not completed blind human adjudication. Therefore we publish no independently verified semantic accuracy percentage.

How are the figures produced?

All source code and fixtures are readable and versioned: synthetic lexical fixtures, report generator, provisional semantic review pack. Independent adjudication is tracked in issue #29.

Can the benchmarks be trusted?

You can reproduce the specific synthetic checker calculations on a pinned commit, but the labels were authored by the project, not adjudicated independently. They must not be treated as evidence that a real assignment, product or business requirement has been satisfied. There is no independent correctness, security or accessibility certification.

Help improve the evidence

Contribute a rights-cleared, fictional test that exposes a false alarm, or help arrange genuine independent human review. Real client prompts, production logs, credentials and undisclosed vulnerabilities must not be posted publicly.
