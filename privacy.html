PUBLIC BETA · DATA HANDLING

Know what leaves your browser.

Updated 29 October 2026. This is a practical explanation of current product behaviour, not an independently audited legal privacy notice. No account is required to try the free website.

1. Paste and compare in the web checker

When you paste requirements and an AI answer into the free browser checker and click the check button, the text is compared locally by JavaScript in that browser session. The website does not intentionally submit that pasted text to the Missing AI backend for this check. It is not saved to a Missing AI account. Your own browser, device, clipboard and extensions remain outside Missing AI's control.

2. Import a public URL

When you press Load URL, your selected URL is submitted to a separately hosted Missing AI fetch service. That service requests readable public HTTPS webpage content and returns the extracted text to your browser. The web checker does not automatically follow every link to other documents. Only public HTML/plain-text URLs are supported; private networks, login-required pages and PDF files are not supported by this importer.

3. Use the optional ChatGPT or Claude MCP connector

When a connected AI host calls Missing AI's remote MCP tools, the relevant source text, selected public source URLs and AI answers may be transmitted to the remote service. The host platform has its own data handling terms, and infrastructure providers may generate access or operational logs. The beta does not provide an independently audited retention period, encrypted-at-rest assurance, or confidential-data guarantee.

4. Retention, analytics and limitations

The open-source application code has no user registration, paid plans, saved checking history or built-in third-party visitor analytics. The fact that the application does not intentionally persist checked text is not a guarantee that hosting, application logs, reverse proxies, network intermediaries or the AI host store nothing. No independent privacy audit has been completed.

5. What not to submit

Do not paste credentials, private client documents, medical or financial information, personal identifiers, private repositories or other confidential source material into the public beta site, URL importer or remote MCP. For sensitive work, assess and self-host the open-source code in infrastructure under your control.

6. Questions and rights

For non-sensitive questions, open a GitHub issue. Issues are public: do not include confidential details or identifiable personal data. For security disclosures, follow the security policy. A private privacy-contact process and audited deletion/retention procedures must be established before broader remote-service promotion.
