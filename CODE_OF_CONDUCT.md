# Missing AI community conduct

We want a constructive, accessible community for users and developers of all experience levels.

Be considerate: discuss ideas, code, evidence and failures rather than attacking people. Assume good faith, ask for clarification, and welcome respectful disagreement about benchmarks and claims. Do not harass, threaten, dox, spam, discriminate, share private information or post exploit instructions targeting real systems.

Project maintainers may edit or remove inappropriate contributions, lock discussions or block participation when necessary. Report abusive comments through the GitHub report mechanism; use a public issue only for non-sensitive process concerns. For private security reports follow [SECURITY.md](SECURITY.md). The maintainer currently has not published a dedicated confidential conduct mailbox; this is a process gap, not a promise of private case handling.

This applies to GitHub issues, pull requests and project-managed discussions, and is intended to support factual, evidence-based collaboration.
