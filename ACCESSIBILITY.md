# Accessibility commitment and current limitations

Missing AI aims to be usable with a keyboard, screen reader, voice input and assistive technologies across common devices.

**Do not assume WCAG 2.2 AA conformance.** The current website has some semantic HTML, labelled inputs and visible focus states, but has not completed an independently verified accessibility audit or disabled-user research. The project cannot currently certify browser/device or assistive-technology coverage.

If you encounter a barrier, open an [accessibility issue](https://github.com/AbdulkadirKhoujja/missing-ai/issues/new/choose) with the affected page/element, browser or assistive technology (if comfortable sharing), expected result and impact. Please avoid sensitive information.

Priority review topics: mobile navigation, colour contrast, keyboard and screen-reader status announcements, copying/exporting reports, errors in form workflows and cognitive readability. Accessibility improvements should carry relevant regression tests and a manual test note. An accessibility statement needs evidence from appropriate testing and must not be fabricated.
