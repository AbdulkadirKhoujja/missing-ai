# Getting help with Missing AI

**Use the web checker:** https://abdulkadirkhoujja.github.io/missing-ai/  
**Quick start, architecture and local setup:** [README](README.md) · [Developer handoff](docs/DEVELOPER_HANDOFF.md)  
**Public problems and feature suggestions:** [Issues](https://github.com/AbdulkadirKhoujja/missing-ai/issues/new/choose)  
**Private vulnerabilities:** [Security policy](SECURITY.md)

Include your environment (Node version, browser, OS), URL type (not confidential URLs), affected component, exact reproducible steps and expected/actual outcome. Remove secrets and personal/client data first.

This is an open-source beta with best-effort maintainer support, **not 24/7 monitored support**. The public web checker is separate from the controlled beta MCP service. GitHub Issues are public and unsuitable for confidential work.
